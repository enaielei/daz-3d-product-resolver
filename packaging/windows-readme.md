# Welcome to Daz 3D Product Resolver

Open **Daz3DProductResolver.exe**. Python and Qt are included; no developer setup is needed.
For the portable ZIP, extract the whole folder and keep `_internal` beside the executable.

1. Add your scene files and the folders holding downloaded product ZIPs or extracted products.
2. Add existing DAZ content libraries. **Find my DAZ folders** can help.
3. Choose where to install, or select **Check only** for a read-only preview.
4. Check, review the products and any choices, then install when ready.

See [the illustrated user guide](docs/user-guide.md) and [troubleshooting](docs/troubleshooting.md).
Copies are whole products. Sources are preserved. No DAZ/DIM settings are changed.
Static references are checked; dynamic/script dependencies may require additional work.

To remove an installed app, use Windows Installed apps. Content installed into your separate
DAZ library is not removed. The portable app can be removed by deleting its extracted folder.
