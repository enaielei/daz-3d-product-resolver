# Contributing

Use Python 3.12+ and `uv sync --locked --all-extras`. Run Ruff and pytest as described
in README. Add meaningful synthetic regression fixtures for behavior changes.
Never submit purchased content, account/profile files, personal paths, credentials,
or real library inventories. Open an issue first for broader discovery adapters.

Use GitHub flow, Conventional Commits and a `codex/` branch for Codex-assisted work.
Keep human authorship and append `Co-authored-by: Codex <noreply@openai.com>` when applicable.
Submit a PR linked to an issue; a human authorizes merges.
